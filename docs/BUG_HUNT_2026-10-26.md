# Bug hunt 2026-10-26

_The method of docs/BUG_HUNT_2026-10.md: every finding is a row with a verdict; a suspected bug became a bug only
after a reproduction or a failing test; every FIXED row names the test that fails on the old code and passes now._

## Engine

_Branch `bughunt/2026-10-26-engine` (off main fdf43ba). Scope: our engine code changed since the last hunt
(13c1323): `engine-rs/crates` (pipeline/, decode, vram, tensorrt, clip, runtime with the Core ML `ck_` rename, ocio,
config, writers, render, job, gpu, outputs, ck-engine) and `engine-rs/export` (Core ML scripts)._

### How it was run

- **Engine (CPU)**: the branch's release engine (default features: ORT static CPU, OCIO), `--device cpu`, the
  `2.0.0-onnx.3` fp32 set, one engine process per batch of jobs, every run under `memrun.sh 8`, the heavy lock and a
  timeout. Inputs made with ffmpeg / cv2 in `~/.cache/claude-scratch/ck-bughunt-26/engine/in`: paths with spaces,
  unicode and quotes; 321x199, 320x200, 200x320 (portrait); 1, 3, 10 and 30 frame clips; a VFR MKV; 12-bit ProRes
  4444; a truncated MP4; linear EXR folders with NaN / +-inf pixels and with frame numbers 65, 66, 70; 16-bit PNG;
  first-frame hints as grey + alpha PNG, RGBA EXR and Y-only EXR; a float EXR hint folder with a NaN; an unwritable
  output folder; protocol misuse (non-UTF-8, broken JSON, arrays, missing fields, `"inf"` numbers, bad windows, bad
  `trt_build` sizes, cancels). Every stdout line of every run was parsed: 1330 lines in 14 runs (CPU and GPU), all
  protocol replies.
- **Engine (GPU)** (allowed by Marcy for this hunt): main's dist engine and the branch's GPU build
  (`ort-dynamic,cuda,tensorrt,ocio`), ORT 1.31 CUDA 13 runtime from the app's install, `2.0.0-onnx.4` fp16, under the
  heavy lock then the GPU lock, a 12 GB cap and a timeout; GPU idle (0 %) before each run (Sonata's app was open, not
  using the card). TensorRT on a scratch copy of the built HD range (`CK_ENGINE_TRT_CACHE`), never the app's cache; no
  engine built.
- **Reference reads**: cv2 4.11 (`OPENCV_IO_ENABLE_OPENEXR=1`) for what the original reads from a hint file; ffprobe
  for every output's size, frame count and colour tags.
- **Severity**: as the last hunt (HIGH = wrong output with no error; MEDIUM = a job or feature fails or an input is
  misread; LOW = a wrong message, a late failure, a path the app doesn't take).

### How it was run

- **Unit**: vitest under `npm run check` (memory-capped, `claude-work.slice`, heavy.lock): 271 tests at the start, 281
  at the end (10 new, one extended). Each new test was run against the old file (`git stash` of the fix) and failed there.
- **Isolated copies, on the GPU** (Marcy allowed the GPU for this hunt: away, Sonata not in use; heavy.lock + gpu.lock,
  `tools/isolated.sh --mem 14G`, a timeout on every run): the dev build (`npm run build`) with a copy of main's
  `engine-rs/target/dist` engine and ck-trt-build, the installed runtime and model set given by `CK_ENGINE_BIN` /
  `_MODELS` / `_ORT` (read only), its own HOME (so its own TensorRT cache and settings), driven over CDP with
  `tools/drive.mjs` (`window.ck` calls, state reads, DOM checks, screenshots). Real jobs: HD 24-frame and 480-frame test
  clips (ffmpeg testsrc2), default video, ½ scale EXR, DNxHR 444 + cutout, a background TensorRT build of HD (268.6 s,
  2.77 GB), a TensorRT job on it, Stop mid-job, the window closed mid-job. Afterwards: no engine, builder, ffmpeg or
  KWin left; `ksecretd` / `kwalletd6` only Marcy's own (started 2026-10-25 17:20).
- **Engine protocol by hand**: `engine/ck_engine.py` (the CorridorKey2.0 checkout's venv) fed the run the app sends.
- **Tools**: `tools/gen_notices.mjs --check`, `tools/verify-feed.mjs` (live feeds), dry-runs of `tools/mac_gate.sh`,
  `tools/window_sweep.sh`, `tools/vs_original.sh`. No release, no upload, no signing key touched.
- **Severity** as the last hunt: HIGH = wrong or lost output with no error, or the machine not shared; MEDIUM = a job
  or feature fails, or files are left behind; LOW = a wrong message, a control that does nothing, a path rarely taken.
